Arena Matchup

Pick the models you care about from all 11 LMArena leaderboards and see which one wins each job. Each effort level (Claude Opus 5.5 High, Claude Opus 5.5 Max) counts as its own model, so you can see what the extra effort buys. Ranks and ratings come from blind human votes; they say nothing about price or context window, which this dataset doesn't include.
